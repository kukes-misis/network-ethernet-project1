Проводная сеть Ethernet, режимы работы и стандарты сетевых устройств

Архитектурное исследование концентраторов, мостов, коммутаторов, маршрутизаторов, сетевых адаптеров (NIC) и стандартов IEEE 802.3. Включает физический бенчмаркинг CSMA/CD, замеры задержек Cut-Through и оценку аппаратной разгрузки процессора хоста.

L1 Physical
Концентратор (Хаб)
Повторяет электрические импульсы со входного порта на все остальные порты без анализа MAC-адресов.
  • 1 общий домен коллизий (Shared Media)
  • Полудуплекс (Half-Duplex)
  • Протокол CSMA/CD
  • 0 буферизации данных
3Com SuperStack Shared Media
L2 Data Link
Сетевой мост (Bridge)
Программно фильтрует и пересылает кадры между сегментами на основе таблицы MAC-адресов на базе CPU.
  • 2 изолированных домена коллизий
  • Программная обработка кадров
  • 1 широковещательный домен
  • Предшественник коммутатора
Cisco 1500 Bridge Software L2
L2 Data Link
Коммутатор (Switch)
Высокоскоростная аппаратная микросегментация трафика с помощью специализированных матриц ASIC.
  • N доменов коллизий (по числу портов)
  • Режимы Cut-Through (0.45 мкс) и Store-and-Forward
  • Полный дуплекс (0 коллизий)
  • Поддержка VLAN (IEEE 802.1Q)
Cisco Catalyst 2960-X Hardware ASIC
L3 Network
Маршрутизатор
Маршрутизирует IP-пакеты между независимыми подсетями с изоляцией широковещательного трафика.
  • N доменов коллизий и broadcast
  • Таблицы маршрутизации RIB/FIB
  • Декремент поля TTL (anti-loop)
  • Трансляция NAT/PAT и списки ACL
Cisco ISR 4331 Network Layer
L1 Physical
Репитер / Усилитель
Преодолевает затухание сигналов в протяженных кабельных линиях связи.
  • Репитер: цифровая регенерация импульсов
  • Усилитель: аналоговое усиление амплитуды
  • Правило 5-4-3 (максимум 4 репитера)
  • Лимит задержки 512 битовых слотов
Ethernet Repeater Signal Restore

LAYER 3
Сетевой уровень
Маршрутизатор (Router L3, Cisco ISR 4331), L3-коммутатор (Catalyst 3850)
  • PDU: Пакет (Packet) | Адресация: Логическая IP (IPv4 / IPv6)
  • Широковещательные домены: N раздельных доменов (полная изоляция подсетей)
  • Домены коллизий: N раздельных доменов (по числу физических портов)
  • Функционал: маршрутизация по таблицам RIB/FIB, декремент поля TTL, трансляция NAT/PAT, фильтрация списков ACL
  • Аппаратная база: сетевой процессор NPU или ASIC для маршрутизации на скорости кабельной линии (Wire-Speed SVI)
LAYER 2
Канальный уровень
Коммутатор (Switch L2, Cisco 2960-X), Мост (Bridge), NIC (MAC-модуль)
  • PDU: Кадр (Frame) | Адресация: Физический MAC-адрес (48 бит / 6 байт)
  • Широковещательные домены: 1 единый домен (или по 1 на каждый VLAN IEEE 802.1Q)
  • Домены коллизий: N раздельных доменов (аппаратная микросегментация)
  • Самообучение: ассоциативная память CAM (Source MAC → Port → VLAN, aging 300 с)
  • Режимы: Cut-Through (задержка 0.45 мкс) и Store-and-Forward (буферизация с проверкой CRC)
  • Защита от петель: протоколы STP (IEEE 802.1D) и RSTP (IEEE 802.1w)
LAYER 1
Физический уровень
Концентратор (Hub L1, 3Com), Репитер (Repeater L1), Усилитель сетевого сигнала
  • PDU: Битовый поток (Bit Stream) | Среда: Витая пара UTP Cat.5e/6, Оптика
  • Широковещательные домены: 1 единый домен на все порты
  • Домены коллизий: 1 единый домен на все порты (Shared Media)
  • Режим работы: полудуплекс (Half-Duplex) по протоколу доступа CSMA/CD
  • Ограничения: правило 5-4-3 (максимум 4 репитера, задержка оборота до 512 bit-times)
  • Регенерация сигнала: восстановление прямоугольной формы импульсов и подавление джиттера
