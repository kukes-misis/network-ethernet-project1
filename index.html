Концентратор (Хаб) L1 OSI
Сетевое устройство, предназначенное для объединения устройств сети в сегменты.

Основной принцип работы: трансляция пакетов, поступающих на один из его портов, на все другие порты без анализа адресов.

• 1 единый домен коллизий
• Полудуплекс (Half-Duplex)
• Протокол CSMA/CD
• 0 буферизации данных
3Com SuperStack Shared Media
Сетевой мост (Bridge) L2 OSI
Сетевое устройство канального уровня модели OSI, предназначенное для объединения нескольких сегментов в единую сеть.

Принцип работы: делит сеть на 2 домена коллизий. Выполняет фильтрацию и пересылку кадров на основе MAC-адресов.

• 2 домена коллизий
• Программная обработка на CPU
• Таблица MAC-адресов
• Предшественник коммутатора
Cisco 1500 Bridge Software L2
Коммутатор (Switch) L2 OSI
Прибор, объединяющий несколько компьютеров и цифровых устройств в локальную сеть.

Принцип работы: передает данные напрямую получателю по CAM-таблице (Source MAC → Port).

• Микросегментация: каждый порт — отдельный домен коллизий!
• Режимы: Cut-Through (0.45 мкс) и Store-and-Forward
• Полный дуплекс (Full-Duplex)
• Поддержка VLAN (802.1Q)
Cisco Catalyst 2960-X Hardware ASIC
Маршрутизатор (Router) L3 OSI
Специализированное сетевое устройство, пересылающее пакеты между различными сетями на основе IP-адресов.

Ключевое отличие: полная изоляция широковещательных доменов (Broadcast Domains).

• Маршрутизация по RIB/FIB
• Декремент поля TTL (anti-loop)
• Трансляция адресов NAT/PAT
• Списки доступа ACL и Firewall
Cisco ISR 4331 Network Layer
Репитер / Усилитель L1 OSI
Устройства физического уровня для преодоления затухания сигнала в кабельных линиях.

Репитер (Повторитель): восстанавливает форму импульсов, устраняет джиттер (регенерация).

Усилитель сигнала: аналоговое усиление амплитуды (усиливает и сигнал, и шум).

• Правило 5-4-3 (max 4 репитера)
• Лимит задержки 512 битовых слотов
Ethernet Repeater Signal Restore

🧱 Архитектурное разграничение оборудования по уровням модели OSI

Сравнительный анализ сетевых устройств, доменов коллизий, широковещательных доменов и методов коммутации.

🌐 Уровень 3: Сетевой (Network Layer)
Маршрутизатор (Router L3, Cisco ISR 4331), L3-коммутатор (Catalyst 3850)
  • PDU: Пакет (Packet) | Адресация: Логическая IP (IPv4 / IPv6)
  • Широковещательные домены: N раздельных доменов (полная изоляция подсетей)
  • Домены коллизий: N раздельных доменов (по числу физических портов)
  • Функционал: маршрутизация по таблицам RIB/FIB, декремент поля TTL (предотвращение петель), трансляция NAT/PAT, фильтрация списков ACL
  • Аппаратная база: сетевой процессор NPU или ASIC в L3-коммутаторах для маршрутизации на скорости кабельной линии (Wire-Speed Inter-VLAN)
🔄 Уровень 2: Канальный (Data Link Layer)
Коммутатор (Switch L2, Cisco 2960-X), Мост (Bridge), NIC (MAC-модуль)
  • PDU: Кадр (Frame) | Адресация: Физический MAC-адрес (48 бит / 6 байт)
  • Широковещательные домены: 1 единый домен (или по 1 на каждый VLAN IEEE 802.1Q)
  • Домены коллизий: N раздельных доменов (аппаратная микросегментация)
  • Самообучение: ассоциативная память CAM (Source MAC → Port → VLAN, aging 300 с)
  • Режимы: Cut-Through (задержка 0.45 мкс) и Store-and-Forward (буферизация с проверкой CRC)
  • Защита от петель: протоколы STP (IEEE 802.1D) и RSTP (IEEE 802.1w)
⚡ Уровень 1: Физический (Physical Layer)
Концентратор (Hub L1, 3Com), Репитер (Repeater L1), Усилитель сетевого сигнала
  • PDU: Битовый поток (Bit Stream) | Среда: Витая пара UTP Cat.5e/6, Оптика
  • Широковещательные домены: 1 единый домен на все порты
  • Домены коллизий: 1 единый домен на все порты (Shared Media)
  • Режим работы: полудуплекс (Half-Duplex) по протоколу доступа CSMA/CD
  • Ограничения: правило 5-4-3 (максимум 4 репитера, задержка оборота до 512 bit-times)
  • Отличие репитера от усилителя: репитер регенерирует цифровой сигнал (убирает джиттер), усилитель усиливает аналоговую амплитуду вместе с шумами
