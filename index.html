📊 Виртуальная интерактивная доска оборудования и стандартов сетей

Архитектурная классификация сетевых устройств, режимов функционирования и стандартов проводных сетей IEEE 802.3.

✓ Материал подготовлен к очной защите проекта
Концентратор (Хаб) L1 OSI
Сетевое устройство физического уровня для объединения узлов в единый сегмент.

Принцип функционирования: побитовое повторение электрических сигналов со входного порта на все остальные порты без анализа MAC-адресов.

• 1 единый домен коллизий (Shared Media)
• Полудуплексный режим (Half-Duplex)
• Протокол доступа CSMA/CD
• Отсутствие внутренней буферизации
3Com SuperStack Физический уровень
Сетевой мост (Bridge) L2 OSI
Устройство канального уровня для объединения двух кабельных сегментов и изоляции коллизий.

Принцип функционирования: программная фильтрация и направленная пересылка кадров на основе таблицы MAC-адресов на CPU.

• 2 изолированных домена коллизий
• Программная обработка кадров
• 1 широковещательный домен (Broadcast)
• Архитектурный предшественник коммутатора
Cisco 1500 Bridge Канальный уровень
Коммутатор (Switch) L2 OSI
Многопортовое устройство канального уровня для высокоскоростной аппаратной коммутации.

Принцип функционирования: микросегментация трафика с помощью CAM-таблицы (Source MAC → Port) на базе ASIC.

• N доменов коллизий (каждый порт изолирован)
• Режимы: Cut-Through (0.45 мкс) и Store-and-Forward
• Полнодуплексный режим (Full-Duplex, 0 коллизий)
• Поддержка виртуальных сетей VLAN (IEEE 802.1Q)
Cisco Catalyst 2960-X Аппаратный ASIC
Маршрутизатор (Router) L3 OSI
Специализированное сетевое устройство для межсетевого взаимодействия на основе IP-адресации.

Ключевое отличие: полная изоляция широковещательных доменов (блокировка Broadcast-штормов).

• Маршрутизация по таблицам RIB/FIB
• Декремент поля TTL (предотвращение петель)
• Трансляция сетевых адресов NAT/PAT
• Списки контроля доступа (ACL) и защита
Cisco ISR 4331 Сетевой уровень
Репитер / Усилитель L1 OSI
Оборудование физического уровня для преодоления затухания сигналов в длинных линиях связи.

Репитер (Повторитель): регенерация формы и амплитуды импульсов, устранение фазового джиттера.

Усилитель сигнала: аналоговое усиление мощности без цифрового восстановления битов.

• Правило 5-4-3 (максимум 4 репитера в тракте)
• Предел круговой задержки: 512 битовых слотов

🧱 Архитектурное разграничение оборудования по уровням модели OSI

Сравнительный анализ сетевых устройств, доменов коллизий, широковещательных доменов и методов коммутации.

🌐 Уровень 3: Сетевой (Network Layer)
Маршрутизатор (Router L3, Cisco ISR 4331), L3-коммутатор (Catalyst 3850)
  • PDU: Пакет (Packet) | Адресация: Логическая IP (IPv4 / IPv6)
  • Широковещательные домены: N раздельных доменов (полная изоляция подсетей)
  • Домены коллизий: N раздельных доменов (по числу физических портов)
  • Функционал: маршрутизация по таблицам RIB/FIB, декремент поля TTL (предотвращение петель), трансляция NAT/PAT, фильтрация списков ACL
  • Аппаратная база: сетевой процессор NPU или ASIC в L3-коммутаторах для маршрутизации на скорости кабельной линии (Wire-Speed Inter-VLAN)
🔄 Уровень 2: Канальный (Data Link Layer)
Коммутатор (Switch L2, Cisco 2960-X), Мост (Bridge), NIC (MAC-модуль)
  • PDU: Кадр (Frame) | Адресация: Физический MAC-адрес (48 бит / 6 байт)
  • Широковещательные домены: 1 единый домен (или по 1 на каждый VLAN IEEE 802.1Q)
  • Домены коллизий: N раздельных доменов (аппаратная микросегментация)
  • Самообучение: ассоциативная память CAM (Source MAC → Port → VLAN, aging 300 с)
  • Режимы: Cut-Through (задержка 0.45 мкс) и Store-and-Forward (буферизация с проверкой CRC)
  • Защита от петель: протоколы STP (IEEE 802.1D) и RSTP (IEEE 802.1w)
⚡ Уровень 1: Физический (Physical Layer)
Концентратор (Hub L1, 3Com), Репитер (Repeater L1), Усилитель сетевого сигнала
  • PDU: Битовый поток (Bit Stream) | Среда: Витая пара UTP Cat.5e/6, Оптика
  • Широковещательные домены: 1 единый домен на все порты
  • Домены коллизий: 1 единый домен на все порты (Shared Media)
  • Режим работы: полудуплекс (Half-Duplex) по протоколу доступа CSMA/CD
  • Ограничения: правило 5-4-3 (максимум 4 репитера, задержка оборота до 512 bit-times)
  • Отличие репитера от усилителя: репитер регенерирует цифровой сигнал (убирает джиттер), усилитель усиливает аналоговую амплитуду вместе с шумами
