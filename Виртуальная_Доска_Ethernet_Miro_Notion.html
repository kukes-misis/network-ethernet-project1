🧱 Архитектурное разграничение оборудования по уровням OSI

🌐 Уровень 3: Сетевой (Network Layer)

Маршрутизатор (Router, Cisco ISR 4331), L3-коммутатор (Catalyst 3850)

  • PDU: Пакет (Packet) | Адресация: IP (IPv4/IPv6)
  • Полная изоляция широковещательных доменов (Broadcast Domains)
  • Маршрутизация по таблицам RIB/FIB, декремент поля TTL, NAT/PAT, ACL
  • Количество доменов коллизий: N (по числу интерфейсов)
  • Количество широковещательных доменов: N (каждый интерфейс — отдельная подсеть)

🔄 Уровень 2: Канальный (Data Link Layer)

Коммутатор (Switch, Cisco 2960-X), Мост (Bridge), NIC (MAC-модуль)

  • PDU: Кадр (Frame) | Адресация: Физический MAC (48 бит)
  • Микросегментация: каждый порт — отдельный домен коллизий
  • Самообучение через CAM-таблицу (Source MAC → Port, Aging 300с)
  • Режимы: Store-and-Forward, Cut-Through, Fragment-Free, Full-Duplex
  • Поддержка VLAN (IEEE 802.1Q) и защита от петель (STP/RSTP 802.1w)

⚡ Уровень 1: Физический (Physical Layer)

Концентратор (Hub, 3Com), Репитер (Repeater), Усилитель сигнала

  • PDU: Бит (Bit Stream) | Среда: Витая пара UTP Cat.5e/6, Оптика
  • Единый домен коллизий (Shared Media): сигнал дублируется во все порты
  • Регенерация формы и амплитуды импульсов, устранение джиттера
  • Работа в полудуплексе (Half-Duplex) по протоколу CSMA/CD
  • Ограничение правилом 5-4-3 (максимальное время оборота 512 битовых слотов)
