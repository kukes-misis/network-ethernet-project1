Концентратор (Хаб) L1 OSI
Сетевое устройство, предназначенное для объединения устройств сети в сегменты.

Основной принцип работы: трансляция пакетов, поступающих на один из его портов, на все другие порты без анализа адресов.

• 1 единый домен коллизий
• Полудуплекс (Half-Duplex)
• Протокол CSMA/CD
• 0 буферизации данных
3Com SuperStack Shared Media
Сетевой мост (Bridge) L2 OSI
Сетевое устройство канального уровня модели OSI, предназначенное для объединения нескольких сегментов в единую сеть.

Принцип работы: делит сеть на 2 домена коллизий. Выполняет фильтрацию и пересылку кадров на основе MAC-адресов.

• 2 домена коллизий
• Программная обработка на CPU
• Таблица MAC-адресов
• Предшественник коммутатора
Cisco 1500 Bridge Software L2
Коммутатор (Switch) L2 OSI
Прибор, объединяющий несколько компьютеров и цифровых устройств в локальную сеть.

Принцип работы: передает данные напрямую получателю по CAM-таблице (Source MAC → Port).

• Микросегментация: каждый порт — отдельный домен коллизий!
• Режимы: Cut-Through (0.45 мкс) и Store-and-Forward
• Полный дуплекс (Full-Duplex)
• Поддержка VLAN (802.1Q)
Cisco Catalyst 2960-X Hardware ASIC
Маршрутизатор (Router) L3 OSI
Специализированное сетевое устройство, пересылающее пакеты между различными сетями на основе IP-адресов.

Ключевое отличие: полная изоляция широковещательных доменов (Broadcast Domains).

• Маршрутизация по RIB/FIB
• Декремент поля TTL (anti-loop)
• Трансляция адресов NAT/PAT
• Списки доступа ACL и Firewall
Cisco ISR 4331 Network Layer
Репитер / Усилитель L1 OSI
Устройства физического уровня для преодоления затухания сигнала в длинных кабельных линиях.

Репитер (Повторитель): восстанавливает форму импульсов, устраняет джиттер (регенерация).

Усилитель сигнала: аналоговое усиление амплитуды (усиливает и сигнал, и шум).

• Правило 5-4-3 (max 4 репитера)
• Лимит задержки 512 битовых слотов
Ethernet Repeater Signal Restore
