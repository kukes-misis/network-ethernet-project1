Проводная сеть Ethernet, режимы работы и стандарты сетевых устройств

Архитектурное исследование концентраторов, мостов, коммутаторов, маршрутизаторов и сетевых адаптеров (NIC) по стандартам IEEE 802.3. Включает физический бенчмаркинг алгоритма CSMA/CD, замеры микросекундных задержек Cut-Through и оценку аппаратной разгрузки CPU хоста.

Сетевой коммутатор (Switch)

Интеллектуальное устройство канального уровня, выполняющее микросегментацию локальной сети на базе специализированных матриц ASIC. Разделяет коллизионные домены на каждый отдельный физический порт и устраняет взаимные помехи при работе в режиме Full-Duplex.

Аппаратная база ASIC / TCAM матрица
Домены коллизий N изолированных (по числу портов)
Режим дуплекса Full-Duplex (без CSMA/CD)
Методы коммутации Cut-Through / Store-and-Forward
Референс: Cisco Catalyst 2960-X IEEE 802.3ab / 802.1Q VLAN
L1 Physical

Концентратор (Хаб)

Повторяет электрические импульсы со входного порта на все остальные без анализа MAC-адресов. Формирует единую разделяемую среду.

  • Домен коллизий: 1 общий
  • Режим: Half-Duplex
  • Арбитраж: CSMA/CD
  • Буферизация: 0 байт
3Com SuperStack Shared Media
L2 Data Link

Сетевой мост (Bridge)

Программно фильтрует и пересылает кадры между сегментами на основе таблицы MAC-адресов на базе центрального процессора.

  • Домены коллизий: 2 изолированных
  • Обработка: Программная (CPU)
  • Широковещание: 1 домен
  • Архитектура: Предшественник Switch
Cisco 1500 Bridge Software L2
L3 Network

Маршрутизатор (Router)

Маршрутизирует IP-пакеты между независимыми подсетями на базе таблиц RIB/FIB с полной изоляцией широковещательного трафика.

  • Broadcast-домены: N раздельных
  • PDU: Пакет (IP)
  • Безопасность: ACL, NAT, VPN
  • Протоколы: OSPF, BGP, RIP
Cisco ISR 4331 Hardware L3
L1 Physical

Репитер / Усилитель

Преодолевает затухание в кабеле. Репитер регенерирует цифровые фронты импульсов; усилитель повышает аналоговую амплитуду сигнала.

  • Регенерация: Устранение джиттера
  • Правило задержки: 5-4-3 (max 4)
  • Задержка: < 5 битовых слотов
  • Фильтрация: Отсутствует
IEEE 802.3 Repeater Signal Boost

Layer 3 — Сетевой уровень (Network Layer)
PDU: Пакет (Packet) • IP-адресация

Устройства: Маршрутизатор (Router), L3-коммутатор (Multilayer Switch). Обеспечивают межсетевое взаимодействие и логическую адресацию.

Широковещательные домены N раздельных доменов — полная изоляция широковещательного шторма между интерфейсами.
Домены коллизий N раздельных доменов (на каждом порту).
Принцип пересылки Поиск наибольшего совпадения префикса (LPM) в таблице FIB/RIB на базе IP-адреса назначения.
Функции безопасности Списки контроля доступа (ACL), трансляция NAT/PAT, межсетевой экран, сегментация подсетей.
Layer 2 — Канальный уровень (Data Link Layer)
PDU: Кадр (Frame) • Физическая MAC-адресация

Устройства: Сетевой коммутатор (Switch), Сетевой мост (Bridge), Сетевой адаптер (NIC). Локальная доставка кадров внутри сегмента.

Широковещательные домены 1 общий домен на весь VLAN (Broadcast-кадры рассылаются во все активные порты).
Домены коллизий N независимых доменов — каждый порт коммутатора изолирован аппаратной матрицей.
Принцип пересылки Аппаратная таблица коммутации (MAC Address Table / CAM): самообучение по Source MAC, коммутация по Destination MAC.
Режимы коммутации Cut-Through (пересылка сразу после 14-го байта кадра, задержка const 0.45 мкс) и Store-and-Forward (буферизация и верификация CRC32).
Layer 1 — Физический уровень (Physical Layer)
PDU: Бит / Электрический импульс / Фотон

Устройства: Концентратор (Хаб), Репитер (Повторитель), Кабельная среда (витая пара Cat5e/6, оптоволокно).

Широковещательные домены 1 общий домен (любой сигнал повторяется на все порты).
Домены коллизий 1 общий домен коллизий (одновременная передача двумя узлами вызывает электрическую коллизию).
Принцип работы Прямая ретрансляция и регенерация электрических сигналов без буферизации и без анализа заголовков.
Ограничения Ограничение по правилу 5-4-3 (максимум 4 повторителя между любыми двумя хостами для гарантии регистрации коллизии).
